# Experimental branch index

There are **36 isolated experimental branches**, one for each numbered proof item
without an exact whole-statement proof of its original formulation. Together they
declare **51 named prerequisite axioms**; **7 branches introduce no new axiom** and
reuse existing facts or provide typed input data. All are **SOURCE_ONLY_UNCOMPILED**.
The existing **9 of 45** exact original proofs and the separate corrected 3.2 result
retain their previous evidence. No new target proof or proof tier is claimed.

Every branch starts directly from
[`00c635cf99744d9fd336369c2382aede5d6c1f99`](https://github.com/randogelist/snditeration/tree/00c635cf99744d9fd336369c2382aede5d6c1f99).
Read-only publication checks matched all 36 branch heads and all **288 file blobs**
(8 changed files per branch). This verifies the published bytes, not compilation,
axiom discharge or mathematical correctness. No Lean was run for this work.
Main receives only this documentation; its certified Lean sources, root imports,
build configuration and CI workflow are unchanged.

Each **target** link preserves the original statement and separately lists repairs,
missing interfaces and discharge obligations. **Typed inputs** are partial research
boundaries, not complete formalizations of the paper item. Named axioms remain
unproved upstream obligations; a zero count does not establish the target either.
Branch links follow live work; target/input links below are pinned to the published
commit. The [machine-readable manifest](EXPERIMENTS.json) records every commit,
tree, named axiom, dependency description, source hash and publication check.
See the [axiom and integration policy](EXPERIMENTAL_AXIOM_POLICY.md).
